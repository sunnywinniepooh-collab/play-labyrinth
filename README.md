Проект: сайт с играми

Файлы:
- index.html — главная страница игрового портала
- style.css — стили портала
- play-labyrinth/index.html — страница игры "Play Labyrinth"
- play-labyrinth/style.css — стили игры
- play-labyrinth/main.js — логика игры
- play-labyrinth/manifest.json — манифест для установки игры
- play-labyrinth/favicon.svg — значок игры
- chess/index.html — страница шахмат
- chess/style.css — стили шахматной доски
- chess/main.js — логика шахмат и AI

Запуск:
Откройте файл `index.html` в браузере, чтобы увидеть портал.
Нажмите «Играть в Play Labyrinth», чтобы открыть игру.

Как играть в Play Labyrinth:
- Управление: WASD или стрелки.
- Работает на русской и английской раскладках.
- Дойдите до монетки, чтобы перейти на следующий уровень.

Как играть в Шахматы:
- Выбирайте сложность AI перед началом партии.
- Кликните по своей фигуре, затем по клетке, куда хотите пойти.
- Играйте белыми против компьютера.

Где можно редактировать:
- `play-labyrinth/main.js` — логика игры, управление, кот и монетка.
- `play-labyrinth/style.css` — стили игрового экрана.
- `play-labyrinth/index.html` — страница игры.
- `index.html` — главная страница портала.
- `style.css` — стили портала.

Добавление новых игр:
- создайте новую папку для игры
- добавьте HTML/CSS/JS файлы
- добавьте ссылку на новую игру в `index.html`

SEO и публикация:
- Чтобы сайт нашли в Google по запросу «play labyrinth», нужно разместить его в интернете.
- Подойдет GitHub Pages, Netlify или Vercel.
- После публикации Google начнет индексировать страницу и показывать результат по ключевым словам.
